HOW TO ADD GAMES

← Back to the game log

The site is static. Every game on the page comes from one file, games.json. To add, change or remove a game you edit that file and publish it again. There are two ways to do it: a script that fills in the cover, trailer and screenshots for you, or editing the file by hand.

Option 1: the script (recommended)

The script tools/add_game.py looks the game up on RAWG and adds it to games.json with its cover, trailer (when RAWG has one) and screenshots. It needs Python 3 and nothing else.

One-time setup

  1. Create a free key at rawg.io/apidocs.
  2. Copy .env.example to .env and put your key in it: 
    RAWG_API_KEY=your-key-here

The .env file is listed in .gitignore, so it is never uploaded to GitHub. Keep it that way: do not paste the key into any page or commit it.

Add a finished game

python3 tools/add_game.py "Hades" --platform PS5 --genre "Roguelike" --finished 2026-10-12

Add a game you are still playing

python3 tools/add_game.py "Sekiro: Shadows Die Twice" --platform PS4 --genre "Souls Like" --status "In progress"

If the script picks the wrong game

List the matches, then run the command again with the id you want:

python3 tools/add_game.py "Resident Evil" --search
python3 tools/add_game.py "Resident Evil" --rawg-id 56183 --platform PS4 --genre "Survival horror" --finished 2026-02-18 --replace

All options

OptionMeaning
--platformPlatform you played on, for example PS5, SNES, PC.
--genreGenre text shown on the page.
--finishedDate finished as YYYY-MM-DD.
--statusUse "In progress" for unfinished games. Leave it out for finished ones.
--notesOptional short note shown under the game.
--rawg-idExact RAWG game id, to skip the search.
--searchOnly list the RAWG matches and stop.
--replaceOverwrite the game if it is already in games.json.

Option 2: add a game from GitHub (no computer needed)

The repository has a workflow that runs the same script for you. You fill in a form on GitHub and the site updates by itself a minute later.

One-time setup

  1. In the repository open Settings → Secrets and variables → Actions, press New repository secret, name it RAWG_API_KEY and paste your RAWG key.
  2. Open Settings → Pages and set Source to GitHub Actions.

Add a game

  1. Open the Actions tab, choose Add game and deploy on the left, then press Run workflow.
  2. Fill in the form. Only the title is always required. Give a finished date, or type In progress in the status field.
  3. Press the green Run workflow button. The workflow adds the game to games.json, saves it to the repository and publishes the site.

If the wrong game is picked, tick search_only and run it to see the RAWG matches in the run summary. Then run it again with the right id in rawg_id and tick replace.

The key is stored as a GitHub secret. It is never written to the site or the repository.

Option 3: edit games.json by hand

games.json is a list. Add one object per game, like this:

{
 "id": "hades",
 "title": "Hades",
 "platform": "PS5",
 "genre": "Roguelike",
 "finished": "2026-10-12",
 "notes": "Released in 2020.",
 "cover": "https://media.rawg.io/media/games/1f4/1f47a270b8f241e4676b14d39ec620f7.jpg",
 "trailer": "",
 "trailerPreview": "",
 "screenshots": []
}
FieldMeaning
idRequired. A short unique name in lowercase with dashes.
titleRequired. The name shown on the page.
platform, genreText shown on the page.
finishedDate as YYYY-MM-DD. Newest dates are listed first.
statusOptional. Add "status": "In progress" for games you have not finished. They appear at the top and show Status instead of a date.
notesOptional text under the game.
coverA full image address, or a file in this project such as covers/hades.jpg. If it is empty or broken, the page shows a coloured box with the game's initials.
trailer, trailerPreviewOptional video file address and its poster image. Leave "" for none.
screenshotsA list of image addresses shown in the details window. Use [] for none.

Keep the commas between objects and use double quotes. You can check the file at jsonlint.com if the page shows no games after an edit.

Using your own cover image

Put the file in the covers/ folder, then set "cover": "covers/your-file.jpg". Keep images small (under about 300 KB) so the site stays fast.

Change or remove a game

To change a game, edit its object in games.json. To remove it, delete the whole object, including its trailing comma if it is the last one. The page order never needs editing: it sorts by date on its own.

Preview on your computer

The page loads games.json, which browsers block when you open the file directly. Start a small web server instead:

python3 -m http.server 8000

Then open http://localhost:8000.

Publish on GitHub Pages

  1. Create a repository on GitHub and push this folder to it. Check that .env is not included.
  2. In the repository, open Settings → Pages and set Source to GitHub Actions.
  3. Run the Add game and deploy workflow from the Actions tab, or push any change to main. Every push to main publishes the site.
  4. After a minute the site is live at https://YOUR-USER.github.io/YOUR-REPO/.

To update the site later, add games, then commit and push:

git add games.json covers
git commit -m "Add Hades"
git push

Good to know

  • Covers, screenshots and trailers from RAWG are loaded from RAWG's servers, and the footer links back to RAWG as their terms ask. RAWG has trailers for few games, mostly newer ones. Older games often have screenshots only.
  • RAWG's main image is often a promotional picture, not a box cover. Use your own image in covers/ if you want real box art.
